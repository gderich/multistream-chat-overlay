# Termos de Uso e Política de Privacidade

## 1. Aceitação
Ao utilizar o Multistream Chat Overlay ("Software"), você concorda com os termos aqui estabelecidos.

## 2. Natureza gratuita e não comercial
O Software é distribuído **gratuitamente**, sem custo de aquisição, assinatura, período de teste ou chave de ativação. Não existe versão "paga" com recursos adicionais: todas as funcionalidades estão disponíveis, igualmente, para qualquer pessoa que baixe o app.

O autor pode, opcionalmente, receber doações voluntárias (ex.: via Pix) como forma de agradecimento. Doações **não geram nenhuma obrigação, garantia adicional, suporte prioritário ou desbloqueio de recursos** — são apenas uma forma livre de apoio ao projeto.

## 3. Uso de Dados
O Software não coleta, não armazena em servidores remotos, e não transmite suas mensagens, senhas ou tokens de autenticação. Todas as configurações são salvas localmente em sua máquina.

As conexões com Twitch, Kick, YouTube e TikTok são feitas diretamente de seu computador para as APIs oficiais dessas plataformas.

O código Pix e o link de redes sociais exibidos no painel "Apoiar" são informações públicas de recebimento do autor, embutidas no próprio app — nenhum dado seu é coletado, enviado ou compartilhado ao gerar o QR Code ou copiar o código.

Por ser um projeto gratuito e mantido de forma voluntária, não há garantia de disponibilidade contínua, correção de bugs em prazo determinado ou suporte formal.

Este software verifica automaticamente por novas versões publicadas no repositório público do GitHub e pode baixá-las e instalá-las com sua confirmação. Nenhum dado de chat ou credencial de plataforma (Twitch/Kick/YouTube/TikTok) é transmitido nesse processo — apenas o necessário para verificar se há uma versão mais recente disponível.
